# OphthaCheck v0.3
Offline-first proof-of-concept for ophthalmic nursing clerking.
Includes nurse profile/PIN prototype, clock-in, local archive, dictation, VA-first rule, red-flag checks, missing-field check, SBAR generation, print/PDF, native Share, WhatsApp and email.
IMPORTANT: GitHub Pages is static. These local profiles are NOT secure hospital authentication and archives are device/browser-local. Do not use real patient-identifiable data until proper authentication, encryption, audit, backup, privacy and regulatory controls are implemented.
The app shell and records work offline after first load. Browser speech recognition may still require network depending on browser/device; truly offline speech needs an on-device speech engine/native app.
